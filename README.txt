URPAQ INCLUSIVE — АВТОНОМНАЯ ВЕРСИЯ

Для запуска не нужны npm, сервер или установка библиотек.

1. Откройте index.html в браузере — это короткая визитка фонда.
2. Кнопка «Полный сайт» открывает foundation.html со всей информацией.
3. staff-portal.html открывает демонстрационный портал персонала.

ВАЖНО

Портал персонала является интерфейсным прототипом с вымышленными данными, которые хранятся только в браузере. Не вводите реальные персональные или медицинские данные. Для рабочей конфиденциальной системы необходимы защищённый сервер, база данных, серверная авторизация, разграничение прав, шифрование, журналирование и резервное копирование.

Для приёма реальных платежей в полном сайте необходимо указать официальный HTTPS-адрес платёжного оператора в настройке paymentUrl. До этого сайт не собирает данные банковских карт и открывает WhatsApp администратора.
