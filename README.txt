URPAQ INCLUSIVE — ГОТОВЫЙ САЙТ БЕЗ NPM

В папке всего две рабочие страницы:

1. index.html — главный публичный сайт фонда.
2. staff-portal.html — демонстрация закрытого технического портала.

Для просмотра достаточно открыть index.html двойным щелчком в современном
браузере. Установка npm, библиотек или сервера не требуется. HTML, CSS,
JavaScript, логотип и фотографии специалистов уже находятся внутри файлов.

Перед публичным запуском необходимо подключить утверждённую платёжную ссылку,
политику конфиденциальности и публичную оферту фонда. Технический портал сейчас
является интерактивным прототипом: для реальной работы с конфиденциальными
данными детей потребуется защищённый сервер, база данных, авторизация,
резервное копирование и журнал доступа.
